# 🤖🧠 VEX AI – Team Exit 6A | High Stakes (2024–2025)

This repository contains the full competition codebase for **Team Exit 6A** for the **VEX AI Challenge – High Stakes (2024–2025 season)**. The project focuses on autonomous robot behavior, AI-driven decision making, and competition-ready reliability using VEX AI hardware of a Jetson Nano and Intel RealSense Cameras.

The goal of this project is to design, test, and deploy an autonomous robot capable of competing effectively in the **High Stakes** game by scoring efficiently, navigating autonomously, and making intelligent decisions under competition constraints.
